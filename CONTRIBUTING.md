# Contributing to sequaint-os

Thanks for helping improve Sequaint OS.

## Rules for this public repo

1. **No private data.** Do not add Sequaint Labs private names beyond "Sequaint Labs", personal or family details, client names, product codenames, or secrets.
2. **Fictional examples only** in templates and docs.
3. **Apache-2.0.** Contributions are licensed under the same licence as the repository.
4. **Branch and PR.** Work on a feature branch. Open a pull request against `main`. Do not push to `main`.
5. **Attribution.** Start every file, commit message, and PR description with the attribution line required by your harness; end commits with `Agent:` and `Directed-by:` trailers.
6. **CI.** The `scan` workflow runs gitleaks and (when configured) a denylist check. Fix any failures before review.

## Suggested workflow

1. Fork or branch from `main`.
2. Edit templates or docs; keep examples generic.
3. Open a PR describing what changed and why.
4. Wait for maintainer review; do not merge your own PR unless you are a maintainer with explicit approval.
